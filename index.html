// sobre

Cada projeto abaixo resolve um problema específico: cálculo de frete, orçamento automático, cadastro de cliente, painel financeiro, busca de profissionais. Cuido da parte técnica e também penso a estratégia por trás, do primeiro commit à manutenção.

SERVIÇO 01 · LOGÍSTICA E DISTRIBUIÇÃO DE ALIMENTOS

ABA Alimentos e Distribuição

Sistema de pedidos com dois fluxos: cestas básicas com tamanho e preço fechado, ou compra sob demanda. Calcula o frete automaticamente pelo CEP, gera orçamento em PDF e organiza o pedido pronto pra confirmar direto no WhatsApp.

  • JavaScript
  • BrasilAPI / ViaCEP
  • jsPDF
  • Geocoding
  • localStorage

SERVIÇO 02 · SAÚDE MENTAL · SITE INSTITUCIONAL

Clínica Prevenire

Site institucional pra uma clínica de psicologia: apresenta a equipe, resultados em números, depoimentos reais de pacientes e um botão de WhatsApp sempre à mão pra marcar consulta sem fricção.

  • HTML / CSS / JS
  • Design responsivo
  • Integração WhatsApp
clinicaprevenire.com.br ↗

SERVIÇO 03 · EDUCAÇÃO PROFISSIONALIZANTE

Instituto Evolutivo de Educação

Catálogo de pós-graduação e cursos organizados por área (saúde, direito, tecnologia, gestão), com carga horária, duração e botão de interesse direto por curso, direcionando pro atendimento.

  • HTML / CSS / JS
  • Catálogo dinâmico
  • Integração WhatsApp
institutoevolutivo.com.br ↗

SERVIÇO 04 · APP MOBILE · SAÚDE MENTAL COMUNITÁRIA

Acolhe+

App mobile de apoio à saúde mental: busca de profissionais por especialidade, avaliações, cadastro e login com sessão persistente. Frontend em React Native/Expo com backend próprio em Node, Express e SQLite.

  • React Native
  • Expo
  • Node.js
